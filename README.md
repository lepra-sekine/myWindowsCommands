# myWindowsCommands

Windows環境向けの自作スクリプト集です。

## 概要

- コマンドプロンプト（.cmd）や PowerShell（.ps1）のスクリプトをまとめています。
- 業務や作業中に「あれば便利だな」と感じた処理を、随時追加していく予定です。
- WindowsコマンドやPowerShellの学習を兼ねて作成しているため、至らない点があるかもしれませんが、利用時は自己責任でお願いいたします。

## フィードバックについて

- 不具合の報告や改善提案などがございましたら、Issueに記載いただけますと幸いです。
- ※長期間リポジトリを確認できないことがあり、対応が遅れる場合がございます。恐れ入りますが、あらかじめご了承ください。

## フォルダ整理について

- 現時点では行っていません。フォルダごと PATH に登録して、cmd や ps1 を名前で呼び出せるようにするためです。
- 今後、スクリプトが増えてきた際には、フォルダ整理も検討します。
