# Auto Delete All Posts

> [!CAUTION]
> **重要：本拡張はログイン中のアカウントの投稿を「全件」削除します。**
>
> **復元はできません。
>
> **導入前に必ず対象アカウントを確認してください。**
> 
> **注意：ダイアログによる確認は行いません。ページ読み込みと同時に処理が開始されるため、導入前に十分ご注意ください。**

## 導入前の最終確認項目

- 対象アカウントでログインしていることを再確認する
- 本拡張をテストする場合は、削除しても問題ないテスト用アカウントで行う
- DOM 変更により動作しなくなる可能性があるため、重大な変更があれば拡張を無効化する

## 使い方

1. Chrome の拡張機能ページ（chrome://extensions/）を開く
2. 「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を選択
4. 本フォルダ（chrome_extension/delete_post）を選択して読み込む
5. X（Twitter）のプロフィールページを開くと、自動で削除処理が開始します
6. 削除処理が完了したら、Chrome の拡張機能ページ（chrome://extensions/）を開き、`Auto Delete All Posts` を削除して Chrome を再起動してください。これは誤操作による再実行を防ぐための対策です。

## 注意事項

- 本拡張を導入する前に、ログイン中のアカウントが削除対象であることを必ず確認してください。削除は「全件」を想定しています。
- 本拡張は投稿を削除します。取り消しはできません。実行前に必ず確認してください。
- 削除対象の投稿が多数ある場合は、ページを再読み込みしながら処理することがあります。
- X（Twitter）の DOM が変更されると動作しなくなる可能性があります。
- 実行中は画面操作が自動化されます。ブラウザの挙動に注意してください。
