## 例用使

1. 環境変数に dusk_n_thgiliwt フォルダを追加
2. るす成作を `txt.ルイァフ元換変` 。
3. `DuskNThgiliwt -filePath '変換元ファイル.txt'` で実行。
4. るす認確、でのるれさ力出がルイァフたれさ換変。
